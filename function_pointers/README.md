# Function Pointers

## 0. What's my name

- 0-print_name.c: Prints a name using a function pointer.
- function_pointers.h: Contains the function prototype.
- 1-array_iterator.c: Executes a given function on each element of an integer array.
- 3-calc.h: Contains the calculator structures and prototypes.
- 3-op_functions.c: Contains the five arithmetic operations.
- 3-get_op_func.c: Selects the operation using a function pointer.
- 3-main.c: Handles arguments and performs the calculation.
