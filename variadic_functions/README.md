# Variadic Functions

## 0. Beauty is variable, ugliness is constant

- 0-sum_them_all.c: Returns the sum of all its parameters.
- variadic_functions.h: Contains the function prototype.
- 1-print_numbers.c: Prints a list of integers separated by a given string.
- 2-print_strings.c: Prints strings separated by a given string, displaying (nil) for NULL strings.
